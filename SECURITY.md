# Security policy

Report a suspected vulnerability privately to the CyberOps maintainers. Use
GitHub's **Security → Report a vulnerability** flow if enabled. If that form
is unavailable, ask a maintainer for a private contact channel before sharing
technical details. Avoid posting secrets, production data or sensitive
assessment output in public issues.

Include the affected revision, impact, affected components and a description
the maintainers can use to assess the issue. Coordinate disclosure with the
maintainers. The current development line is `main`.
